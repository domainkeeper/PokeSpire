# Asset Research — PokéSpire

## Tilesets Found

### Kenney Roguelike/RPG Pack
- **Source:** https://kenney.nl/assets/roguelike-rpg-pack
- **License:** CC0 1.0 Universal
- **Contents:** 1700+ 16x16 tiles (floors, walls, flora, doors, furniture, mining, flags, UI)
- **Format:** Spritesheet (968x526 PNG) + individual tiles
- **Use:** Route/terrain tiles, environment objects
- **Downloaded:** public/assets/tiles/roguelike/

### Kenney RPG Pack (Base Set)
- **Source:** https://kenney.nl/assets/rpg-urban-pack (also on OpenGameArt)
- **License:** CC0 1.0 Universal
- **Contents:** 229 individual 64x64 tiles (grass, dirt, water, buildings, trees, fences, doors)
- **Format:** Individual PNGs (rpgTile000-rpgTile228)
- **Use:** Primary tileset for town/route ground tiles
- **Downloaded:** public/assets/tiles/kenney-rpg/

### Ninja Adventure Asset Pack
- **Source:** https://pixel-boy.itch.io/ninja-adventure-asset-pack
- **License:** CC0
- **Contents:** Complete RPG kit (tilesets, characters, monsters, UI, music, SFX)
- **Format:** 89 MB zip with full Godot project
- **Status:** Not downloaded (89 MB too large for this prototype phase)
- **Note:** Could be used for future expansion

## Pokémon Sprites

### PokéAPI Sprites
- **Source:** https://github.com/PokeAPI/sprites
- **License:** CC0 (compilation), Nintendo IP (characters)
- **Contents:** Gen 5 animated sprites, front/back for all species
- **Use:** Overworld Pokémon sprites in Route 1
- **Downloaded:** public/assets/pokemon/ (8 species, 2 variants each)
